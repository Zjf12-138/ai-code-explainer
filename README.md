打开浏览器，地址栏输入 chrome://extensions/（Edge 是 edge://extensions/）
打开右上角的 “开发者模式” 开关。
点击左上角的 “加载已解压的扩展程序”。
选择你刚刚创建的 ai-code-explainer 文件夹。
如果一切正常，你会看到一个名为 “AI 代码解释器” 的卡片，没有报错。
点击 Chrome 工具栏右侧的 拼图图标，找到“AI 代码解释器”，点击右侧的 图钉 把它固定在工具栏。
点击插件图标，会弹出一个小窗口，输入你的 DeepSeek API Key，点击保存。（如果你还没有 DeepSeek API Key，去 platform.deepseek.com 注册获取点击扩展图标，在弹出窗口中输入 API Key（以 sk- 开头）Base URL 默认已填写 https://api.deepseek.com/v1，不需要修改点击保存）
打开一个包含代码的网页（比如 GitHub、Stack Overflow，或者你本地的学习笔记）。
选中一段代码，然后右键，会看到菜单中多了一项 “AI 代码解释”。
点击它，页面右侧会滑出一个漂亮的面板，AI 会逐字显示解释结果。
你可以拖拽面板的标题栏移动位置，或拖拽右下角改变尺寸
点击 📋 按钮复制解释内容
解释完成后，面板底部会出现一个输入框

这个扩展不只做一次性代码解释，它更像一个内嵌在网页中的代码对话助手。你选中一段代码获得初步解释后，可以随时在面板底部追问——比如问复杂度、问重构建议、问语言原理。整个对话历史都会保留在面板中，方便对比查看。
